🌐 الجزء C: اتجاه تحسين النت البطيء (مبدئي)

C.1 — المشكلة الأساسية

معماريتك الحالية تُحمّل 39 ملف JS عند بدء التشغيل. على نت بطيء (2G/3G في سوريا):

· ~500KB JS خام → ~150KB مضغوط
· 30+ اتصال Firebase عند boot
· listener واحد على الأقل لكل موديول

C.2 — الاستراتيجيات المقترحة (للنقاش)

1. تقليل قراءات Firebase فوراً

· 🔴 إصلاح _pmScanRecent — الأهم
· 🟠 استخدام orderByChild('time').startAt(cutoff) بدل قراءة كامل
· 🟠 تقليل heartbeat من 20s → 60s

2. Lazy load للموديولات

· 🔴 ملف boot-lite.js يشغّل الأساسيات فقط (auth + chat + rooms)
· 🟠 الموديولات الثقيلة (king, bots, voice, stories) تُحمَّل عند الحاجة

3. Connection Quality Detection

· 🟠 ملف net-quality.js:
  · يقيس زمن الاستجابة
  · يصنف: fast / medium / slow
  · يعدّل السلوك حسب التصنيف

4. Adaptive Intervals

· 🟠 heartbeat: 20s (سريع) / 60s (بطيء)
· 🟠 typing indicator: 4s (سريع) / لا يظهر (بطيء)
· 🟠 presence refresh: 30s → 90s
· 🟠 cleaners: كل 6h (سريع) / كل 24h (بطيء)

5. Service Worker + Cache-First

· 🟠 sw.js مع Stale-While-Revalidate
· 🟠 تخزين كل JS/CSS محلياً بعد أول تحميل

6. Boot Loader متقدم

· 🟠 شاشة تحميل تُظهر التقدم الحقيقي
· 🟠 تسمح بالتفاعل مبكراً مع login screen

7. تقليل حجم CSS

· 🟠 دمج 8 ملفات CSS → 2 (core.css + theme.css)
· 🟠 حذف !important الزائدة (موجودة في v1 بكثرة)

8. Message Pagination أذكى

· 🟠 بدل limitToLast(50) → limitToLast(20) في البداية
· 🟠 تحميل المزيد عند التمرير (موجود في v2)
